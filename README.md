# Оратор от души

Мобильное веб-приложение для практики публичных выступлений. Автор проекта — Андрей Шишмарев, основатель школы «Оратор от души».

## Возможности

- 104 темы в восьми категориях; следующая тема не повторяет текущую.
- 30 секунд подготовки и до 60 секунд выступления, с автоматической остановкой.
- Четыре шага структуры речи доступны во время подготовки и записи.
- Запись через MediaRecorder, прослушивание и скачивание в формате, поддерживаемом браузером (WebM, MP4/M4A или Ogg).
- Достижения: количество тренировок, суммарное время, дни занятий и история тем.
- Русский интерфейс, адаптивная вёрстка, управление с клавиатуры, поддержка уменьшенного движения.

Без регистрации, сторонних API, аналитики, платных сервисов и внешних шрифтов. Аудио не отправляется на сервер. Текущая запись хранится в памяти вкладки; скачайте её перед новой попыткой или закрытием страницы. История содержит только тему, дату и длительность, хранится в localStorage этого браузера. Очистка данных сайта удалит историю. Тренировка учитывается при наличии аудио и длительности хотя бы в одну секунду; досрочная остановка тоже учитывается. Автоматических оценок речи нет.

## Запуск на компьютере

Нужен Node.js 20 или новее (проверено с Node.js 24).

```sh
cd /workspace/orator-ot-dushi
npm ci --ignore-scripts --no-audit --no-fund
npm start
```

Откройте `http://localhost:3000`. Внешних зависимостей нет, сборка не нужна. Для другого порта: `PORT=8080 npm start`. Сервер разработки предназначен для локальной работы; для публикации используйте статический HTTPS-хостинг.

```sh
npm run check
npm test
```

## Публикация в GitHub Pages

1. Сохраните файлы проекта в ветке `main` подключённого репозитория.
2. В GitHub откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
3. В разделе **Actions** запустите «Проверка и публикация» через **Run workflow**, если он ещё не запустился после сохранения.
4. После успешного выполнения GitHub покажет адрес сайта в **Settings → Pages**. Открывайте его через HTTPS и разрешите микрофон.

Workflow сначала выполняет проверки, затем публикует только пять публичных файлов. Сервер Node.js на хостинге не нужен. Можно также загрузить `index.html`, `style.css`, `app.js`, `core.js`, `icon.svg` в одну папку любого статического HTTPS-хостинга. Приложение поддерживает размещение в подпапке.

## Микрофон и смартфоны

Используйте актуальный Safari на iPhone или Chrome на Android. Запись требует HTTPS (исключение для локальной разработки — localhost). Обычный HTTP по IP компьютера не предоставляет доступ к микрофону. Формат записи выбирается через `MediaRecorder.isTypeSupported`, а не по модели устройства. При отказе отображается инструкция; разрешение можно изменить в настройках сайта браузера.

Не сворачивайте браузер и не блокируйте экран во время выступления: мобильная ОС может приостановить JavaScript или микрофон. Таймер использует реальное время и корректируется после возвращения во вкладку, но остановка точно в фоновом режиме не гарантируется браузерами.

На настоящем iPhone и Android нужно проверить разрешение/отказ, звук с физического микрофона, полную минуту записи, воспроизведение, скачивание (на iOS может открыться системное меню), звонок во время записи и возвращение после блокировки экрана. Эти проверки не заменяются тестовым микрофоном на компьютере.

## Проверки первой версии

Модульные тесты проверяют полноту базы, смену категорий и тем, вычисление таймера, чтение повреждённой истории. Дополнительно выполнен браузерный сценарий в Chromium с тестовым микрофоном: мобильная ширина 390 px, смена темы, подготовка, досрочный старт, ручная и автоматическая остановка, аудиоплеер, сохранение истории после перезагрузки и отказ в разрешении. Автоматическое истечение длинных таймеров проверялось с ускорением системного времени внутри тестовой вкладки. Реальные смартфоны пока не проверены.
